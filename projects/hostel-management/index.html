PROJECT OVERVIEW

Built around everyday hostel operations.

The live app provides student admission, automatically generated permanent IDs, automatic roll numbers, roll-based search, a live student list and local backup/restore. The interface states that data is managed safely on the device and that exported backups contain students, attendance, fees, rooms and history.

HIGHLIGHTS

Core functionality

Student admission

Capture student name, guardian, village/city and optional mobile number.

Permanent student ID

Generate a permanent ID that is designed not to change or repeat.

Roll-number search

Quickly find a student using the current roll number for daily operations.

Backup & transfer

Export and restore complete local data as a JSON backup.
